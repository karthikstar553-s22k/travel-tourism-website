# 🌐 Incredible India & World Expeditions — Global GPS & AI Travel Platform

An advanced, GPS and AI-enabled worldwide travel platform covering destinations across **India, Asia, Europe, the Americas, Africa, and Oceania**.

---

## 🛰️ Core Features

- **High-Precision GPS Location Engine**:
  - Real-time GPS status bar with Decimal, DMS, and UTM coordinates selector
  - GPS signal indicator, auto-refresh interval toggle, and manual refresh
  - Heading, speed, elevation, and accuracy tracking (±1–3m)
  - GPS route sharing with direct links for Google Maps, Apple Maps, and Waze
- **AI Distance & Travel Route Analyzer (`#ai-distance`)**:
  - Calculate accurate road, high-speed rail, and flight travel distances (km and miles) between ANY two cities worldwide.
  - Quick route presets for iconic journeys: *Delhi ➔ Agra*, *Paris ➔ Rome*, *Tokyo ➔ Kyoto*, *Mumbai ➔ Dubai*, *New York ➔ London*, *Bangkok ➔ Bali*, *Sydney ➔ Auckland*.
  - Road toll fee estimates, fuel expenses, and recommended expressways.
  - High-speed train options (Vande Bharat, Shinkansen, Eurostar, Frecciarossa).
  - Recommended midway scenic stopovers along the journey.
- **24/7 Personal AI Trip Guide ("Aarav")**:
  - Interactive floating guide concierge in bottom-right corner.
  - Expertise in heritage palaces, international itineraries, flight planning, visa essentials, local etiquette, and street food safety.
  - Text-to-speech audio narration toggle (`🔊`/`🔈`).
  - Fast answers powered by server-side `gemini-3.8-flash`.
- **Interactive Leaflet Mapping**:
  - Full-screen interactive map with worldwide markers for luxury resorts, boutique hotels, and dining hubs.
- **Hotels & Restaurants Booking System**:
  - Luxury 5-Star (e.g. *The Ritz Paris*, *Burj Al Arab Dubai*, *The Plaza New York*, *Taj Lake Palace Udaipur*).
  - Mid-Range & Budget Stays worldwide.
  - In-app reservation modal with check-in/out dates, guest count, and special requests.
- **Trip Cost & Route Planner**:
  - Live budget breakdown based on transit mode, accommodation tier, food, and activities.
- **Bookings Management ("My Bookings")**:
  - View all active reservations, cancel bookings, and click "Navigate to Venue" for direct GPS turn-by-turn navigation.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000).

### 3. Build for Production
```bash
npm run build
```
